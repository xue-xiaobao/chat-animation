# 内置内容导演

本文件只负责“讲什么、怎样讲清楚、怎样把论证变成镜头”。视觉材质、构图和运动语言由选中的内部风格文件决定；静态帧数量、视频任务拆分和跨转场旁白由 [transitions.md](transitions.md) 决定。

## 1. 内容判断

先回答：

1. 这是事实、概念、观点、故事还是操作方法？
2. 观众看完后能用哪一句话复述？
3. 哪个具体情境最适合作为钩子？
4. 哪 3–5 个机制或证据支撑结论？
5. 哪些适用边界不能省略？

不要先想画面再硬塞观点。先确定论证，再为每个论证单位寻找视觉关系。

## 2. 研究与边界

涉及金融、医学、法律、时效信息或专业事实时：

- 先检索权威或第一方来源；
- 记录每个来源具体支持什么；
- 区分事实、理论、推断和建议；
- 写明适用条件、争议和常见误解；
- 不用孤立案例冒充普遍规律。

研究写入 `script.json.research`，但口播只保留理解结论所需的信息。

## 3. 叙事弧

默认从下列结构中按主题取舍：

```text
具体情境或钩子
→ 常见直觉
→ 反常冲突
→ 概念命名
→ 机制展开
→ 适用边界
→ 行动或判断
→ 记忆句
```

不是每条视频都要八段俱全，但必须有冲突、机制和结论，不能只有连续金句。

## 4. 台词

- 不看画面也能听懂。
- 一镜推进一个论证单位。
- 第一次出现专业词时用日常语言解释。
- 口语化，但不靠语气词填充。
- 因果关系要说完整，不让画面替台词补逻辑。
- 中文规划统计汉字、英文字母和数字组成的有效字符；编导层只记录字符数，不在用户声音尚未确定时写死字符速度。
- 结尾给出可复述的判断，不重复开头。
- 有过渡动画时，台词必须跨越转场，不为转场留下无声空档。

如果一句话包含两个独立因果、两个时空或两个结论，拆镜；如果两句只是改写同一件事，合并。

## 5. 分镜

每镜记录：

- `purpose`：它在论证中完成什么；
- `narration`：完整口播；
- `caption_phrases`：按语义和停顿切分；
- `emotion`：这一镜的情绪功能；
- `visual.meaning`：观众需要看懂的关系；
- `visual.metaphor`：一句可拍的视觉命题；
- `visual.elements`：3–6 个可分离组；
- motion plan 要求的状态帧与 `assembly_order`；所有状态帧必须有叙事内容；
- 与所选转场模式匹配的自包含图像提示词；
- 自包含的 `motion_prompt`。

镜头数量服从论证，不服从固定时长。不要为凑镜头切碎完整句子。

锁定分镜后，把每镜有效字符数交给运动层。用户接受内置“白桦”声音配置时使用该配置的内置基线；替换声音或语速指令时先生成一次代表性 TTS 样片并测量字符速度，再计算 `target_duration_seconds = 有效字符数 × 当前声音秒/字`。Agnes 在 24fps 下使用 `8n+1` 帧，当前范围 81–441 帧；预计超过 `18.375 秒` 的镜头必须在自然语义停顿处拆镜，不能先生成最长片段再用变速把它拉长。时长较长的镜头还应把运动写成多个有先后顺序的轻量节拍，避免单一动作持续十几秒。

## 6. 转场规划

默认选择 `hard-cut`，转场时长为 0。用户明确要求过渡动画时，优先选择目标时长 1.0 秒的 `transition-separated`；只有画面简单且明确优先减少任务时选择 `transition-fused`。

先写内容场景，再为相邻场景寻找一个连续锚点。独立转场只负责从前景完成态连接到后景初始态；融合转场把当前内容动作与进入下一状态写成两个清晰节拍。把状态、任务和台词交接点写入 `state/motion-plan.json`。

过渡动画的台词边界默认落在转场中点：上一场景台词覆盖前半段，下一场景台词覆盖后半段。不要给转场另写一句解释性口播，也不要留静音。

## 7. 视觉隐喻

不要把抽象词原样画成文字。依次提炼：

1. 核心意思：观众最终要看懂什么；
2. 关系：谁作用于谁，什么在增加、减少、阻塞或连接；
3. 动词：推开、抱住、漏掉、拴住、分叉、压缩、组装；
4. 物件：轨道、锚、漏斗、时钟、桥、门、齿轮、容器；
5. 歧义：最容易被误读成什么。

视觉隐喻表达关系，不重复台词中的名词。最终材质、色彩、关键帧和运动约束必须来自选中的内部风格定义。

## 8. 自检

- 一句话结论能否独立成立；
- 台词是否脱离画面仍然完整；
- 每镜是否带来新信息；
- 事实与推断是否分开；
- 是否说明关键适用边界；
- 每镜是否只有一个视觉命题；
- 视觉命题能否不用文字表达；
- 每镜是否只有 3–6 个关键组；
- 总字数是否匹配目标时长；
- 图像和运动提示词是否同时遵守所选风格。
- 三种转场策略是否只选了一种并写入 request、script 与 motion plan；
- 独立转场是否默认 1.0 秒，旁白是否在转场中点无缝交接。
