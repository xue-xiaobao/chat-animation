## 1. 选择规则

转场是独立于视觉风格的剪辑策略。先选择风格，再选择转场模式。

规范 ID：

- `hard-cut`：硬切；
- `transition-separated`：过渡动画—独立转场；
- `transition-fused`：过渡动画—融合转场。

默认使用 `hard-cut`。只有用户明确要求过渡动画时，才在 `transition-separated` 与 `transition-fused` 中选择；需要更稳定、可控的高质量过渡时优先使用前者，需要减少任务且画面足够简单时可使用后者。

独立转场的成片默认时长固定为 `1.0` 秒。用户可以明确指定其他时长；没有明确要求时不要自行延长。供应商原始视频可以更长，但合成层只变速转场画面到目标时长，不变速口播。

## 2. 三种模式

### 2.1 `hard-cut`

这是默认模式。适用：不做过渡动画、静态画面、节奏需要明确断点，或相邻场景没有可靠视觉锚点。

策略：

- 静态视频：每个叙事场景只生成一张完成态画面，按口播时长停留，场景边界直接切换；
- 场景内部仍需运动时：每个场景独立生成自己的首尾帧和内容动画，但相邻视频直接切换；
- 不提交额外转场视频任务；
- 台词边界与硬切点对齐。

任务量：静态模式为 `0` 个视频任务；内部动画模式为 `N` 个内容视频任务。

### 2.2 `transition-separated`

这是可选的高质量动画转场模式。

对相邻内容场景 A、B，生成三类任务：

```text
A0 → A1：场景 A 内容动画
A1 → B0：独立转场动画
B0 → B1：场景 B 内容动画
```

完整 N 场景项目通常需要 `N` 个内容任务和 `N-1` 个转场任务。转场直接复用 `A1` 与 `B0`，不额外生成重复静帧。

内容任务只描述场景内部运动，禁止提前进入下一场景。转场任务只描述 A1 到 B0 的连续变化，禁止再承担内容解释。两者拆开可降低手部、人物和物体在复杂提示词中被放大、重绘或变形的概率。

独立转场成片默认 `1.0` 秒。转场越短越好，但必须仍能辨认共享锚点和变化方向。优先使用构图中已有的圆环、纸带、容器、箭头或主体轮廓连接两景；禁止先清空背景再重新出现。

### 2.3 `transition-fused`

适用：画面元素少、运动简单、共享锚点强，并且希望减少生成任务。

对连续状态 A、B、C：

```text
A → B：场景 A 内部动作 + 到场景 B 的转场
B → C：场景 B 内部动作 + 到场景 C 的转场
```

默认每个叙事状态只生成一张静帧；N 个状态通常需要 `N-1` 个视频任务。每个动作提示词必须写成两个清晰节拍，并记录内部动作结束、转场开始和转场中点的位置。最后一个状态如果仍有独立口播，可保持克制呼吸，或在确有内容运动时额外生成 terminal content clip。

融合模式比独立转场少任务，但一次生成同时承担内容运动和跨场重组，更容易出现物体突变、比例漂移和身份重绘。出现这类问题时，不要继续堆叠负面提示词，改回 `transition-separated`。

## 3. 静态帧与视频任务

静态帧契约由转场模式决定，不能先固定“每镜两张图”再选择运动策略。

| 模式 | 默认静态帧 | 视频任务 | 跨场约束 |
| --- | --- | --- | --- |
| `hard-cut` | 静态时每场景一张；有内部运动时每场景首尾两张 | 0 或 N | 无 |
| `transition-separated` | 每场景内容首帧与完成尾帧 | N 个内容任务 + N-1 个转场任务 | 转场复用前景尾帧和后景首帧 |
| `transition-fused` | 每个叙事状态一张 | 通常 N-1 | 每个任务从当前状态到下一状态 |

所有实际生成的状态帧都必须有叙事内容，不得用纯色空白帧。静态帧数量首先服从转场模式；内容任务内部的首尾关系再服从风格快照中的 `frame_policy`：`distinct-first-end` 使用不同的初始态与完成态，`shared-hero-frame` 为同一内容任务复用一张权威主画面。允许在相邻任务之间复用同一个边界状态文件，因为它是连续性的锚点；不要为相同像素重复调用图片模型。

编导层必须把最终选择写入 `request.json`、`script.json` 和 `state/motion-plan.json`。视觉层按 motion plan 决定要生成哪些状态帧；运动层不得反过来临时改变视觉契约。

## 4. 旁白时间线

转场不是独立的无声叙事段。只要存在过渡动画，旁白必须跨越它。

独立转场的分配规则：

```text
场景 A 台词 = 场景 A 内容动画 + A→B 转场前半段
场景 B 台词 = A→B 转场后半段 + 场景 B 内容动画 + B→C 转场前半段
场景 C 台词 = B→C 转场后半段 + 场景 C 内容动画
```

相邻台词在转场中点无缝交接。上一句结束的同一时刻，下一句立即开始；禁止为转场插入静音、黑场或额外口播。字幕启用时也在同一语义边界切换。

融合转场没有独立文件，因此必须在 motion plan 中记录融合片段的转场区间。合成层把台词交接点对齐到该区间中点，而不是简单对齐视频文件边界。

硬切模式中，台词边界直接对齐画面切点。

MiMo WAV 始终是总时钟。先得到全部 clean WAV 时长，再反算内容动画和转场的输出时长。独立转场优先保持目标 `1.0` 秒；剩余时间分配给内容动画。只变速无声画面，不变速有声内容。

## 5. 提示词与 QA

独立内容任务必须包含：

- 只做当前场景内部动作；
- 不进入下一场景；
- 固定背景、机位、主体身份和最终状态。

独立转场任务必须包含：

- Image 1 是前景完成态，Image 2 是后景初始态；
- 指定唯一连续锚点和退出、进入顺序；
- no empty reset、no hard cut、no unrelated object；
- 不重复内容动画，不生成声音和文字。

融合任务必须包含：

- 第一节拍：当前场景内部动作；
- 第二节拍：沿共享锚点进入下一状态；
- 明确两个节拍的百分比；
- 禁止中途清空、整体随机 morph 或重绘人物结构。

QA 除通用首尾帧检查外，还要检查：

- 独立转场成片时长是否等于计划值，默认 `1.0` 秒；
- 转场中点是否与相邻台词交接点一致；
- 整条音轨是否没有转场静音；
- 融合模式是否出现尺寸突变、身份重绘或同时运动过载；
- 硬切是否发生在完整语义和稳定构图上，而非动作中途。
